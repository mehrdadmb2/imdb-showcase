IMDb Showcase — Cinema Vault v2.0.1

This package replaces the previous V4/V15 project snapshot. See README.md for the complete updated architecture and README-V20-RANKING-IMPORT.md for the ranking and CSV import design.

Important deployment notes:
- GitHub Pages is published from docs/ by GitHub Actions.
- src/ratings.csv remains the authoritative IMDb export; keep it tracked in Git.
- docs/movies.json is the canonical Pages dataset and is regenerated by update-movies.yml.
- Worker deployment files are in worker/. Deploy worker/index.js with Wrangler after confirming that worker/wrangler.toml uses the EXISTING D1 database ID and binding DB.
- Do not create a new D1 database and do not remove existing database tables or secrets.
- Keep WORKER_PING_SECRET identical between the Cloudflare Worker and GitHub Actions repository secret.
- The Worker GitHub token needs Contents read/write and Actions read/write for CSV import and workflow dispatch.

See worker/README.md for exact Wrangler commands and verification steps.
