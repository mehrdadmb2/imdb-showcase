## ⚙️ نصب و راه‌اندازی

### ۱. کلون کردن پروژه

```bash
git clone https://github.com/mehrdadmb2/imdb-showcase.git
cd imdb-showcase
```

### ۲. دریافت کلید OMDb API

1. به سایت [OMDb API](http://www.omdbapi.com/apikey.aspx) بروید.
2. یک کلید رایگان دریافت کنید.
3. ایمیل فعال‌سازی را تأیید کنید.

### ۳. تنظیم Secrets در گیت‌هاب

در مخزن خود، به **Settings → Secrets and variables → Actions** بروید:

| نام Secret | مقدار | وضعیت |
|:---|:---|:---|
| `OMDB_API_KEY` | کلید دریافتی از OMDb | **اجباری** |
| `IMDB_COOKIES` | رشته کوکی‌های IMDb | اختیاری |

> **💡 نکته**: برای دریافت کوکی‌ها، وارد IMDb شوید، F12 بزنید، به بخش **Application → Cookies** بروید و کوکی‌های `at-main`، `session-id`، `ubid-main` و `session-token` را به صورت زیر ترکیب کنید:
> ```
> ubid-main=...; session-id=...; at-main=...; session-token=...
> ```

### ۴. فعال‌سازی GitHub Pages

1. به **Settings → Pages** بروید.
2. در بخش **"Build and deployment"**:
   - **Source** را به **"GitHub Actions"** تغییر دهید.

### ۵. اجرای اولین به‌روزرسانی

1. به برگه **Actions** بروید.
2. روی workflow **"به‌روزرسانی و انتشار سایت"** کلیک کنید.
3. روی **"Run workflow"** کلیک کنید.

### ۶. مشاهده سایت

پس از اتمام، سایت در آدرس زیر در دسترس است:

```
https://mehrdadmb2.github.io/imdb-showcase/
```

## 🔄 روش‌های دریافت اطلاعات

| اولویت | روش | توضیح |
|:---|:---|:---|
| ۱ | **کوکی IMDb** | اسکریپت با استفاده از کوکی‌ها مستقیماً به IMDb متصل می‌شود. |
| ۲ | **فایل CSV** | در صورت شکست روش اول، از فایل `src/ratings.csv` استفاده می‌کند. |

> **📌 نکته**: برای استفاده از روش CSV، از صفحه‌ی Ratings در IMDb، روی دکمه **"Export"** کلیک کرده و فایل را در پوشه `src/` با نام `ratings.csv` ذخیره کنید.

## 🤖 اتصال به ربات تلگرام (اختیاری)

برای دریافت اعلان‌های خطا و اجرای دستی به‌روزرسانی:

1. با `@BotFather` در تلگرام یک ربات بسازید و توکن دریافت کنید.
2. یک Worker در Cloudflare بسازید.
3. کد ربات را در Worker قرار دهید.
4. متغیرهای محیطی را تنظیم کنید.
